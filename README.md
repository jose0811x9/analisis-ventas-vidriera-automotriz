# Análisis de ventas de una vidriería automotriz (datos simulados)

Proyecto de análisis de datos con **Python y pandas**. Analiza un año de ventas de una vidriería de vidrios para autos (ficticia): parabrisas, ventanas, ventoleras y vidrios laterales.

> Todos los datos de este proyecto son **inventados (simulados)**. No pertenecen a ningún negocio real.

## Qué responde el análisis

- ¿Qué productos generan más ingresos?
- ¿En qué meses se vende más?
- ¿Quiénes son los mejores clientes?
- ¿Cuánto gasta un cliente en promedio por compra?

## Qué incluye

1. Generación de datos simulados (600 ventas, año 2025).
2. Revisión y limpieza de datos (valores vacíos y filas repetidas).
3. Cálculos con `groupby` (por producto, mes y cliente).
4. Tres gráficos con matplotlib.
5. Conclusiones calculadas con código.

## Herramientas

Python · pandas · numpy · matplotlib · Google Colab

## Cómo ejecutarlo
